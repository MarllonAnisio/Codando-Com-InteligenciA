# ☕ Prompt: Java e Orientação a Objetos

> [!NOTE] Sobre este Prompt
> O objetivo aqui é simular um cenário de entrevista para desenvolvedor Junior. O prompt obriga a IA a avaliar seu conhecimento em Java não apenas com teoria, mas com cenários de código.

## 📋 Como usar
Copie o bloco de texto abaixo e cole no Gemini ou ChatGPT.

---

### O Prompt

```text
me faça um questionário de Java e Orientação a Objetos e tente identificar se eu tenho algum gap de conhecimento e quais sao esses gaps

Caso meu conhecimento seja suficiente para responder todas perguntas, me sinalize pois seguirei meus estudos
Seja analítica nas minhas respostas e veja se há conceitos ou técnicas que faltam eu aprender.
```

---

## ✅ O que fazer depois?
- Se a IA apontar que você tem dificuldades em algo específico (ex: Polimorfismo), abra sua IDE (IntelliJ, Eclipse) e escreva um código de 30 linhas aplicando esse conceito para provar para si mesmo que entendeu.
